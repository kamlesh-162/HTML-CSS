# HTML, CSS & JavaScript Projects

A collection of web pages, responsive layouts, interactive UI components, and mini-projects built using HTML, CSS, and JavaScript.

## 📌 About
This repository contains various frontend projects and coding examples created to practice and improve web development skills. It includes responsive designs, interactive features, DOM manipulation, and JavaScript-based applications.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (ES6+)

## 📂 Contents
- Web page layouts
- Responsive designs
- UI components
- Styling experiments
- JavaScript fundamentals and practice examples
- DOM manipulation and event handling
- Arrays, objects, and functions
- Local Storage
- Promises, Fetch API, and REST APIs
